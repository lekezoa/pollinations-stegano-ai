# SteganoArt AI 👁️

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**SteganoArt AI** is an AI steganography and visual secret encoding platform built on **Pollinations AI**, created for **POLLEN-QUEST #18367**.

## 🎯 Background & Inspiration
Inspired by research on Claude Fable 5.1 and LLM steganography (*"How does Fable 5.1 hide messages in images?"*), SteganoArt AI enables users to hide secret text, cryptographic keys, and coordinates within AI-generated imagery and reconstruct them using vision and language models.

## 🚀 Features
- **Visual Scene Secret Encoding:** Generate high-resolution visuals embedded with concealed data streams.
- **Multimodal Message Decoding:** Extract and decrypt hidden payloads from image carriers.
- **BYOP (Bring Your Own Pollen):** Integrated OAuth login so users authenticate and spend their own Pollen credits.
- **App Key Binding:** `pk_DJzonDcZRXo3452Q`

## 🛠️ Tech Stack
- Frontend: HTML5, Tailwind CSS, JetBrains Mono & Plus Jakarta Sans
- API: [Pollinations.ai](https://pollinations.ai) image & multimodal endpoints
